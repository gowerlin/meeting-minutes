## 1. 播放列與同步

- 找得到可播放的原始檔（`media.status == "found"`）時，`.dock` 一律是「原始錄音／原始影片：<檔名>」＋ `<audio controls preload="metadata">`。時間碼點播、「▶ 播放這段」、`.` 鍵、播放速度、音量都照舊作用在這個元素（`el.audio`），行為與 1.1.1 播放錄音時相同。
- 原始檔是影片（`media.type == "video"`）時另建浮動視窗（§2），裡面放 `<video muted playsinline disablepictureinpicture disableremoteplayback>`，`src` 與播放列相同（同一個 `/api/doc/<id>/media`，伺服器照舊支援 Range）。
- 〔規格決定〕**兩個元素、以播放列為主同步**，而不是一個 `<video>` 搭自製控制列：播放列保留瀏覽器原生控制（播放速度選單、音量、鍵盤操作、輔助技術），和錄音完全相同；代價是影片會另外向本機服務要一次資料（只在 127.0.0.1）。
  - 播放列的 `play`、`pause`、`ended`、`seeked`、`ratechange` → 影片跟著（播放／暫停、`currentTime`、`playbackRate`）。
  - `timeupdate`：兩者差距大於 **0.3 秒**才校正影片的 `currentTime`。
  - 最小化時影片暫停（省資源），還原時先對齊時間再接著播。
  - 點影片畫面＝播放列的播放／暫停。
  - 影片畫面瀏覽器不能解碼時（例：HEVC 的 `.mov`），視窗裡寫「瀏覽器不能顯示這個影片的畫面；聲音照常從下方的播放列播放。」
- 只能有一個聲音來源：影片 `muted`（屬性與 `defaultMuted` 都設），頁面上 `<audio>` 1 個、`<video>` 1 個〔實測：瀏覽器測試檢查〕。

## 2. 浮動影片視窗

### 2.1 版面

```text
┌─┬────────────────────────────┬───┬───┐
│◤│ 影片：<檔名>                │ − │ □ │   標題列 32 px（拖曳＝移動；雙擊＝最大化／還原）
├─┴────────────────────────────┴───┴───┤   ◤＝左上角調整大小（14 px）
│                                      │
│          影片畫面（保持比例）          │   object-fit: contain，底色黑
│                                      │
└──────────────────────────────────────┘
```

- 「可放區域」＝頂端列下緣與底部播放列上緣之間、左右是視窗內寬，**四邊各留 12 px**（`GAP`）。頂端列換行、播放列或瀏覽器視窗大小改變時重新計算（`resize`＋`ResizeObserver`）。
- 視窗高度＝畫面寬 ÷ 影片比例 ＋ 標題列 32 px ＋ 外框 2 px。影片比例取 `videoWidth / videoHeight`，載入前用 16:9。
- 外框、標題列、按鈕用主題 token（`--surface`、`--band`、`--line-strong`、`--ink`、`--accent`、`--shadow`），深色與淺色都跟著變；畫面區底色固定黑色（影片的黑邊）。

### 2.2 三種狀態

| 狀態 | 位置與大小 | 進入 | 離開 |
|---|---|---|---|
| `small`（預設） | 右下角；畫面寬 **320 px**（16:9 時 320×180）；可拖曳與調整大小 | 預設；最大化時按「❐」、`Esc`、雙擊標題列；最小化前是 `small` 時點標籤 | — |
| `max` | 可放區域內最大、保持比例置中；不能拖曳與調整大小 | 「□」、雙擊標題列、標題列有焦點時 `Enter`／空白鍵 | 「❐」、`Esc`、雙擊 → 回到原本的 `small` 位置與大小（最大化不改記住的小視窗位置） |
| `min` | 視窗隱藏；右下角「▶ 影片」標籤（`.btn.vtab`），離右邊與播放列上緣 12 px；聲音照常 | 「−」 | 點標籤 → 回到最小化前的狀態（`small` 或 `max`） |

- 小視窗的位置用「離可放區域右下角的距離」（`r`、`b`）記，所以沒拖過的視窗不論視窗大小都貼著右下；拖到哪就記到哪。
- **拖曳**（Pointer Events＋pointer capture）：標題列移動；不能拖出可放區域（停在邊上）。**調整大小**：拖左上角，右下角固定、保持比例；畫面寬 **200～960 px**，而且整個視窗要放得進可放區域（區域太小時以區域為準，可小於 200）。
- **瀏覽器視窗縮小**：顯示時收回可放區域，但不改記住的值；視窗放大後回到原位〔規格決定〕。
- **鍵盤**：標題列可取得焦點（`tabindex="0"`，`aria-label`「影片視窗標題列：方向鍵移動、Shift＋方向鍵調整大小、Enter 最大化或還原」）：方向鍵移動 16 px、`Shift`＋←／↑ 放大 32 px、`Shift`＋→／↓ 縮小 32 px、`Enter`／空白鍵最大化或還原。按鈕是 `<button>`，都有 `title` 與 `aria-label`（「最小化影片視窗（聲音照常播放）」「最大化影片視窗」／「還原成小視窗」，最大化鈕另有 `aria-pressed`）。最小化後焦點移到標籤；從標籤還原後焦點回到標題列。
- 校稿快捷鍵（`J`、`A`、`Enter`…）在影片視窗與標籤上不作用（`onKey` 略過 `.vwin, .vtab` 裡的按鍵），避免按鈕上按 `Enter` 時同時開啟標記選單。
- `Esc`：只有 `max` 時作用；標記選單或對話框開著時先由它們處理（先關選單，再按一次才還原）。鍵盤說明（`?`）的 `Esc` 列與新增的「方向鍵（影片標題列）」列寫明。

### 2.3 記住狀態

- `localStorage` 鍵 **`mmproof-video`**，值是 JSON：`{"state": "small"|"max"|"min", "rest": "small"|"max", "w": <畫面寬 px>, "r": <px>, "b": <px>}`（`rest`＝最小化前的狀態）。
- 狀態切換、拖曳或調整大小結束、鍵盤移動後寫入。讀寫都包 `try/catch`：讀不到、不是 JSON、欄位不對 → 用預設；寫不進去 → 不影響操作。
- 存在瀏覽器（不跟著稿）：開任何一份稿都沿用上次的狀態；位置先收回可放區域再顯示。
- 和 `mmproof-theme`（主題）一樣是單純的偏好，不寫進 `.proofread/`，**存檔格式不變**。

### 2.4 窄畫面（≤ 760 px）

- 沒有記住的狀態時，預設是 `min`（只有「▶ 影片」標籤）。
- 有記住的狀態或使用者點開時，小視窗的寬度跟著可放區域縮小；最大化同樣只到可放區域。
- 不會產生橫向捲動〔實測：375×812 scrollWidth 375〕。窄畫面照 1.1 規格只能檢視。

### 2.5 z-index 次序

| 元素 | z-index |
|---|---|
| 右側面板的分頁列（sticky） | 2 |
| **浮動影片視窗 `.vwin`、最小化標籤 `.vtab`** | **20** |
| 選取文字的工具列 `.seltool` | 25 |
| 標記選單、修改選取文字 `.pop` | 30 |
| 提示 `.toast` | 35 |
| 對話框 `.modal-bg` | 40 |

影片視窗（任何狀態）都在標記選單、工具列與對話框下面。最大化時可以蓋住逐字稿；這時仍可用鍵盤（`J`／`K`、`Enter`）開標記選單，選單在影片上面。
