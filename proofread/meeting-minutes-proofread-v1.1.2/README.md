# 會議記錄校稿（meeting-minutes-pro 的附屬工具）

> 版本 1.1.2｜需要 meeting-minutes-pro 2.2.0 以上｜Windows、macOS｜MIT 授權

會議記錄校稿是 **meeting-minutes-pro**（下稱 Pro）的附屬工具：把 Pro 轉寫並 AI 校正後的逐字稿，在瀏覽器裡一處一處確認、修改，
最後產出沒有任何標記的**定稿逐字稿**與**定稿字幕**，並把校稿得到的經驗匯入 Pro 的錯誤對照表與詞表，讓下一場轉寫更準。

- 在自己的電腦上執行：用 Pro 已經裝好的 Python 開一個只有本機能連的小服務，用預設瀏覽器開啟。不需要網路、不多裝任何套件。
- 一鍵開啟：Windows 對輸出資料夾按右鍵「傳送到 → 會議記錄校稿」；macOS 把輸出資料夾拖到「會議記錄校稿.app」上。不需要打任何指令。
- 可以同時開好幾份稿（每份一個分頁），關掉再開會接著校。
- 機敏會議（Pro 2.4.0 的**本機限定**）也能用：校稿全在本機，只有「用定稿重做會議記錄」會送出內容，本機限定時它會停用（見 [§ 5.1](#51-本機限定機敏會議)）。

**1.1.2 的改變**（修正）：原始檔是影片時，1.1.1 把影片照原始大小放進底部播放列，畫面會撐開版面、蓋住逐字稿。
1.1.2 起底部播放列不論錄音或影片都只放播放控制（高度相同），影片的畫面改放在**浮動影片視窗**：預設是右下角的小視窗，
可以最大化、最小化、拖曳移動與調整大小，狀態會記住（見 [§ 4.1](#41-影片視窗)）。存檔格式與其他功能不變。

**1.1.1 的改變**（安全修正）：Pro 的 `config.json` 讀不了（沒有權限、被鎖住、不是 UTF-8、不是合法的 JSON、空檔、最外層不是物件），
或 `privacy.local_only` 的值看不懂（`"true"`、`1`、`null` 等）時，1.1.0 當成「不是本機限定」；1.1.1 起**當成本機限定**
（同 Pro 2.4.1），頁首、說明列、重做區塊與首頁寫明原因與恢復方法。另修正首頁卡片的提示字：只有全域設定時，1.1.0 誤寫
「輸出資料夾有 local-only.json」，現在依來源寫（全域設定、標記檔、config.json 讀不了）。

**1.1.0 的改變**：認得 Pro 2.4.0 的本機限定（全域設定 `privacy.local_only`，或輸出資料夾的標記檔 `local-only.json`）：
「用定稿重做會議記錄」停用並寫明原因；頁首、提示列與首頁的清單標示「本機限定」。人工修改、定稿、經驗匯入照常。
搭 Pro 2.2／2.3 時一樣認得標記檔（與設定裡有的話的全域鍵）。

## 1. 需要什麼

| 項目 | 說明 |
|---|---|
| meeting-minutes-pro | **2.2.0 以上**，而且是用 Pro 的安裝程式裝在這部電腦上（本工具裝在 Pro 的資料夾裡，用 Pro 的 Python） |
| 作業系統 | Windows 10／11；macOS（Apple Silicon，與 Pro 相同） |
| 瀏覽器 | 預設瀏覽器（Chrome、Edge、Safari、Firefox 的近期版本） |
| 輸出資料夾 | Pro 轉寫產生的 `<檔名>_minutes` 資料夾，裡面要有 `transcript.md`（有 AI 校正時另有 `transcript.corrected.md`） |

Claude App（對話／Cowork）的沙盒沒有本機服務，**不能**在 App 裡使用本工具；在 App 裡請照舊讓 Claude 依 `transcript.corrected.md` 補校。

## 2. 安裝

1. 先完整解壓縮下載的 `meeting-minutes-proofread-v1.1.2-installer.zip`。
2. 執行解開後資料夾裡的安裝程式：
   - **Windows**：雙擊 `install.cmd`（不需要系統管理員）。
   - **macOS**：在 `install.command` 上按右鍵 →「打開」（第一次會被 Gatekeeper 擋，用右鍵開啟即可）。
3. 安裝程式會：
   - 檢查 Pro（位置、版本、相容性）。沒有 Pro 或版本太舊時會停下並說明，**不會寫入任何檔案**。
   - 把程式複製到 Pro 資料夾裡的 `proofread/`：
     Windows `%LOCALAPPDATA%\meeting-minutes-pro\proofread\`；macOS `~/Library/Application Support/meeting-minutes-pro/proofread/`
     （有設定環境變數 `MEETING_MINUTES_PRO_HOME` 時改在那個資料夾）。
   - Windows：建立右鍵「傳送到 → 會議記錄校稿」，並讓雙擊 `會議記錄校稿.mmproof` 用本工具開啟（只寫目前使用者的設定）。
   - macOS：建立 `~/Applications/會議記錄校稿.app`，並讓雙擊 `會議記錄校稿.mmproof` 用它開啟。

**升級**：直接執行新版的安裝程式。執行中的校稿會先存檔再關閉，程式換成新版；最近的稿清單與每份稿的校稿進度都保留。

**Pro 升級後**：工具還在（Pro 的安裝程式不會動 `proofread/`），右鍵與 `.app` 繼續有效。開啟時會重新檢查相容性，不相容時會提示到哪裡下載相容版本。
Pro 重建了 Python 環境而且位置改變時，請重新執行本工具的安裝程式。

## 3. 開啟一份稿

| 方式 | 怎麼做 |
|---|---|
| 右鍵（Windows） | 選一個或多個輸出資料夾 → 右鍵 →「傳送到」→「會議記錄校稿」。對錄音檔本身按右鍵也可以（會找旁邊的 `<檔名>_minutes`） |
| 拖放（macOS） | 把一個或多個輸出資料夾拖到「會議記錄校稿.app」上 |
| 雙擊 `會議記錄校稿.mmproof` | 第一次開啟某份稿後，輸出資料夾裡會出現這個小檔（不含任何路徑，資料夾搬家也能用）；之後雙擊它就接著校 |
| 首頁 | 瀏覽器開著時，首頁列出開著的稿與最近的稿，按「接續」 |

- 服務會自動啟動，不會出現命令列視窗；**所有分頁都關掉約 3 分鐘後自動結束**，不用另外關閉。
- 每份稿一個分頁。同一份再開一次，不會開出第二個能修改的分頁：新分頁會提示「這份稿已經在另一個分頁開啟」，原分頁的標題會閃爍；
  要改在新分頁編輯就按「改在這個分頁編輯」。
- 一次選超過 10 份時只開首頁，從首頁逐份開啟。
- 選到的不是輸出資料夾（裡面沒有 `transcript.md`）時，會用一個對話框列出來。

## 4. 校稿

逐字稿裡 AI 校正留下的標記會明顯標示，點一下（或用鍵盤）決定怎麼處理：

| 標記 | 意思 | 可選 |
|---|---|---|
| `{原文→修正}` | AI 改過的地方（含刪除 `{原文→}`、補字 `{→補字}`） | 修正、原文、自由輸入 |
| `[?原文｜推測]` | AI 沒把握、需要確認 | 推測、原文、自由輸入 |
| `{原文→統一}` | 全文用字統一 | 統一寫法、原文、自由輸入 |

- 狀態：未處理 `●`（待確認 `?`）、已確認 `✓`、已改 `✎`、已退回 `↺`。每種狀態同時用形狀、圖示、顏色與文字區分，不只靠顏色。
- 「同樣的標記還有 N 處未處理，一起套用」可以一次處理同樣的錯字。
- **標記以外的文字也能改**：選取文字 → 「✎ 修改選取文字（E）」→ 輸入新文字。改過的地方會成為「人工修改」，之後可再改或刪除（回到原文）。
  選取範圍不能跨到標記；要在兩字之間補字，請選取相鄰的一個字改成「該字＋補字」。
- 頂端有全篇進度「已處理 n／N」與「只看未處理」；點段落的時間碼會從那裡播放原始錄音或影片（找得到原始檔時）。
- 視窗寬度小於 760px 時只能檢視、不能修改。
- 原始檔是影片時，畫面在浮動影片視窗裡（下一節）。

**鍵盤**

| 鍵 | 動作 |
|---|---|
| `J`／`N`、`K`／`P` | 下一個／上一個未處理的標記 |
| `A` | 接受建議並跳到下一個 |
| `R` | 退回（用原文）並跳到下一個 |
| `E` | 自由輸入（有選取文字時＝修改選取的文字） |
| `Enter`、`1`～`3`、`Esc` | 開啟選單、選選項、關閉（影片最大化時 `Esc` 還原成小視窗） |
| `Ctrl＋Z`／`Ctrl＋Y`（macOS `⌘`） | 復原／重做（關掉再開仍可復原） |
| `Ctrl＋S`（macOS `⌘S`） | 立刻儲存 |
| `.`、`U`、`?` | 從目前段落播放、只看未處理、鍵盤說明 |
| 方向鍵（影片視窗標題列） | 移動影片小視窗；加 `Shift` 調整大小；`Enter` 最大化或還原 |

### 4.1 影片視窗

原始檔是影片（`.mp4`、`.m4v`、`.webm`、`.mov`）時，底部播放列和錄音一樣只放播放控制，影片的畫面在浮動視窗裡。
聲音只從底部播放列出來；視窗裡的畫面跟著播放列播放、暫停、跳轉與變速（點畫面也可以播放或暫停）。

| 狀態 | 樣子 | 怎麼切換 |
|---|---|---|
| 小視窗（預設） | 右下角，約 320×180，保持影片比例；不蓋住頂端列與底部播放列 | 拖曳標題列移動；拖左上角調整大小（寬 200～960 px） |
| 最大化 | 放大到頂端列與底部播放列之間，保持比例置中 | 標題列的 `□`；再按一次（`❐`）或按 `Esc` 回到原本的小視窗 |
| 最小化 | 收成右下角的「▶ 影片」標籤，聲音照常播放 | 標題列的 `−`；點標籤還原 |

- 狀態、位置與大小記在這個瀏覽器裡，下次開任何一份稿都沿用；位置超出畫面時會自動收回。瀏覽器視窗縮小時也會收回可視範圍。
- 視窗寬度 760px 以下時預設是最小化標籤。
- 標記的選單、選取文字的工具列與對話框一律在影片視窗上面，不會被擋住。

## 5. 存檔、接續與定稿

**存檔**

- 每次修改後約 1 秒自動儲存。頂端固定的存檔狀態列隨時告訴你目前狀態：`✓ 已儲存 HH:MM:SS`、`儲存中…`、`● 有未儲存的變更`、`✕ 儲存失敗`。
- 儲存失敗時會顯示原因，修改仍在分頁裡、每 5 秒自動重試，也可以按「立刻重試」。
- 有未儲存的變更時關分頁，瀏覽器會先問「確定要離開嗎？」。
- 校稿進度存在**各輸出資料夾**的 `.proofread/` 裡（跟著資料夾搬移、備份）。再次開啟會顯示「接續上次的校稿：上次儲存 …、已處理 n／N 處」。
- 側欄「紀錄」列出這份稿做過的動作（時間、動作、檔名；不記逐字稿內容）。

**定稿**（按「定稿…」才會做，不會自動覆蓋任何檔）

| 產生的檔 | 內容 |
|---|---|
| `transcript.final.md` | 定稿逐字稿：沒有任何標記，格式與校正版相同（講者對應保留） |
| `transcript.final.srt` | 定稿字幕：沿用 Pro 的字幕對時（需要 `transcript.json`） |

- 按下後先出現**確認畫面**（要寫哪些檔、先備份成什麼檔名），確定後出現**結果畫面**（實際寫入的檔、筆數、備份檔名、「開啟資料夾」）。
- 不會修改 `transcript.md`、`transcript.corrected.md` 與其他字幕檔。再次定稿時，舊的定稿檔會先改名備份。
- 還有未處理的標記時，要勾「仍要定稿」：校正與用字統一照建議、待確認寫成「原文〔?推測〕」。
- **名詞寫法同步**：定稿後可以把校稿確認的寫法套用到會議記錄／筆記（`meeting-minutes.md`、`notes.md`），只改名詞寫法、不改摘要的其他內容；
  改之前先備份，有網頁版時一起重新產生。
- **用定稿重做會議記錄／筆記**（選用，會呼叫 AI、要花費）：需要 **Pro 2.3.0 以上**。按下後先顯示供應商、模型與預估費用，確認才執行。
  Pro 2.2.x 時按鈕停用並顯示「升級 meeting-minutes-pro 到 2.3.0 以上就能用」；本機限定時也停用（下一節）。

### 5.1 本機限定（機敏會議）

Pro 2.4.0 起，機敏會議可以用「會議轉寫（Pro，本機限定）」轉寫（輸出資料夾會有標記檔 `local-only.json`），或在 Pro 的 `config.json`
把 `privacy.local_only` 改成 `true`（整部電腦都是本機限定）。這時 Pro 不做 AI 校正與 AI 整理，**用會議記錄校稿人工校稿**就是主要的做法：

- 可以直接校 `transcript.md`（沒有校正版也可以），一處一處改、產生定稿逐字稿與定稿字幕。
- 經驗匯入照常：校稿得到的「原文 → 正確寫法」與新名詞匯入對照表與詞表，下次轉寫更準。
- **「用定稿重做會議記錄」停用**：那一步會把定稿送到 GPT 或 Claude。按鈕下寫明原因與解除方法。
- 頁首在檔名旁標「本機限定」（滑鼠移上去看原因），頁面上方有一行說明；首頁清單在那一份旁標「本機限定」，全域設定時首頁標題旁標「本機限定（整部電腦）」。
- 要解除：這一份 → 刪除輸出資料夾裡的 `local-only.json`；全部 → Pro 的 `config.json` 的 `privacy.local_only` 改回 `false`。重新整理頁面就會更新。
- 〔1.1.1〕Pro 的 `config.json` **讀不了或值看不懂**時也當成本機限定（寧可多擋，不外送）：首頁標題旁標「本機限定（config.json 讀不了）」，
  頁首標示與「用定稿重做」的說明寫出原因（例「config.json 讀不了：不是合法的 JSON（第 3 行第 5 欄）」）、檔案路徑與恢復方法：
  修好 `config.json`，或刪掉它再重新執行 Pro 的安裝程式（重建的 `config.json` 本機限定是關）。不存在時照舊不是本機限定。

## 6. 經驗匯入（對照表與詞表）

側欄「經驗整理」從這份稿的校稿結果整理出「原文 → 正確寫法」與新名詞，勾選後匯入 Pro 的錯誤對照表 `corrections.tsv` 與詞表 `glossary.txt`，
**下次轉寫時生效**。

- 符合 Pro「固定錯誤」條件的詞對預設勾選（原文至少 2 字、每次出現都改成同一個寫法、本場至少出現 2 次、不與對照表衝突、不是一般英文單字……）；
  不符合的照樣列出並寫出原因，可以自己決定要不要勾。與對照表衝突的不能勾。
- 匯入前先把兩個檔備份到 Pro 資料夾的 `backups/`；匯入的列備註為 `proofread:<日期> <來源檔名>`。
- 按「復原上次匯入」可以還原（匯入後兩個檔沒有再被改過時）。

## 7. 移除

- **Windows**：執行安裝包裡的 `uninstall.cmd`；安裝包已經刪掉時，對 `%LOCALAPPDATA%\meeting-minutes-pro\proofread\uninstall.ps1` 按右鍵 →「用 PowerShell 執行」。
- **macOS**：在安裝包裡的 `uninstall.command` 上按右鍵 →「打開」；或在終端機執行 `bash ~/Library/Application\ Support/meeting-minutes-pro/proofread/uninstall.sh`。

移除程式會停止執行中的服務（開著的分頁先存檔），刪除程式、設定、右鍵「傳送到」、`.mmproof` 的雙擊開啟（macOS 是 `.app`），並問要不要刪除最近的稿清單（預設保留）。
**不會刪除**：各輸出資料夾的 `.proofread/`（校稿進度）、定稿檔、Pro 的 `corrections.tsv`、`glossary.txt` 與 `backups/`。

**要移除 Pro 時**：Pro 2.3.0 以上的解除安裝會自動先移除會議記錄校稿；**Pro 2.2.x 請先移除會議記錄校稿，再移除 Pro**
（否則右鍵「傳送到」與 `.mmproof` 的關聯會留下來、指向已不存在的檔）。

## 9. 隱私與安全

- **全部在本機**：服務只接受這部電腦本身（127.0.0.1）的連線，區網與網際網路都連不到；所以 Windows 防火牆不會跳出詢問。
