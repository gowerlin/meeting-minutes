# 用會議記錄校稿確認逐字稿

**這頁幫你了解**：一份稿從打開、逐處確認、定稿到匯入對照表的完整步驟。

會議記錄校稿要另外安裝，而且要先裝好 Pro（見[安裝會議記錄校稿](/install/proofread)）。各功能的畫面見[會議記錄校稿](/features/proofread)。

## 開啟

| 系統 | 怎麼做 |
|---|---|
| Windows | 對會議的輸出資料夾（`<檔名>_minutes`）按右鍵 →「傳送到」→「**會議記錄校稿**」。可以一次選好幾個資料夾；對錄音檔本身按右鍵也可以，會自動找旁邊的 `<檔名>_minutes` |
| Windows／macOS | 雙擊輸出資料夾裡的「會議記錄校稿.mmproof」（第一次開啟某份稿後才會出現，之後用它接著校最方便） |
| macOS | 把輸出資料夾拖到「會議記錄校稿.app」上 |

開啟後：

- 預設瀏覽器會出現一個新分頁，標題是「`<資料夾名稱>`｜會議記錄校稿」，畫面捲到第一個還沒處理的標記。
- 背後的服務自動啟動，**不會出現命令列視窗**，也不用自己關：所有分頁關掉約 3 分鐘後會自動結束。
- 一次選超過 10 份時只開首頁，再從首頁逐份開啟。選到的不是輸出資料夾（裡面沒有 `transcript.md`）時，會跳出對話框列出來。

## 鍵盤操作

| 鍵 | 動作 |
|---|---|
| `J`／`N` | 下一個未處理的標記 |
| `K`／`P` | 上一個未處理的標記 |
| `Enter` | 開啟目前標記的選單 |
| `A` | 接受建議（修正、推測、統一；待確認沒有推測時＝確認原文）並跳到下一個 |
| `R` | 退回（用原文）並跳到下一個 |
| `E` | 有選取文字時＝修改選取的文字；否則＝目前標記的自由輸入 |
| `1`～`3` | 選單裡選第幾個選項 |
| `Ctrl＋Z`／`Ctrl＋Y`（或 `Ctrl＋Shift＋Z`） | 復原／重做；macOS 用 `⌘`。關掉再開也能復原 |
| `Ctrl＋S`（macOS `⌘S`） | 立刻儲存 |
| `.` | 從目前段落播放 |
| `U` | 只看未處理（切換） |
| `?` | 鍵盤說明 |
| `Esc` | 關閉選單或對話框；影片最大化時還原成小視窗 |
| 方向鍵（影片視窗的標題列） | 移動影片小視窗；加 `Shift` 調整大小；`Enter` 最大化或還原 |

在輸入框裡打字時，上面的單鍵不會被攔截。

## 影片視窗 {#video}

原始檔是影片（`.mp4`、`.m4v`、`.webm`、`.mov`）時，畫面下方的播放列和錄音一樣只放播放控制，影片的畫面在一個浮動視窗裡（1.1.2 起；1.1.1 以前影片放在播放列裡，畫面大時會蓋住逐字稿）。

- **聲音只從下方的播放列出來**。浮動視窗的畫面跟著播放列播放、暫停、跳轉與變速；點畫面也可以播放或暫停。點段落的時間碼、`.` 鍵、選單的「▶ 播放這段」都照舊。
- 浮動視窗有三種狀態：
  - **小視窗**（預設）：右下角，約 320×180，保持影片比例，不會蓋住頂端列與下方的播放列。**拖曳標題列**移動，**拖左上角**調整大小（保持比例，寬 200～960 px）；拖到畫面外會停在邊上。
  - **最大化**：按標題列的 `□`（或雙擊標題列），放大到頂端列與播放列之間、保持比例置中。再按一次 `❐`、或按 `Esc`，回到原本的小視窗位置與大小。
  - **最小化**：按標題列的 `−`，收成右下角的「▶ 影片」標籤，**聲音照常播放**；點標籤還原。

- **用鍵盤**：用 `Tab` 移到影片視窗的標題列（影片視窗排在頁面的最後），方向鍵移動、`Shift`＋方向鍵調整大小、`Enter` 最大化或還原；兩個按鈕也能用 `Tab` 選到。
- **會記住**：狀態、位置與大小記在這個瀏覽器裡，下次開任何一份稿都沿用。位置超出畫面時（例如換到比較小的螢幕）會自動收回；瀏覽器視窗縮小時也會收回，放大後回到原位。
- 最大化時影片會蓋住逐字稿，但標記的選單、選取文字的工具列與對話框一律在影片上面。想邊看畫面邊校稿，用小視窗。
- 視窗寬度 760px 以下時，預設是最小化的「▶ 影片」標籤。

## 存檔與接續

- **不用按存檔**：每次修改後約 1 秒自動儲存。想確定時按頂端的「儲存」或 `Ctrl＋S`，畫面會浮出「已儲存 HH:MM:SS（已處理 n／N 處）」。
- 頂端的存檔狀態列：

| 顯示 | 意思 |
|---|---|
| `✓ 已儲存 HH:MM:SS` | 最近一次修改已經寫進資料夾 |
| `● 有未儲存的變更` | 剛改過，馬上會自動儲存 |
| `儲存中…` | 正在寫入 |
| `✕ 儲存失敗（原因見下方）` | 寫不進去；原因寫在頂端的紅色提示 |
| `唯讀（這個分頁不會儲存）` | 這份稿在另一個分頁編輯中，或視窗太窄 |

- **儲存失敗時**：修改還在分頁裡，不會遺失；每 5 秒自動重試，也可以按「立刻重試」。常見原因是資料夾在唯讀位置（例如光碟、沒有寫入權限的網路磁碟），或資料夾被搬走、刪除。
- **關掉再開**：再次開啟同一份稿，頂端會顯示「接續上次的校稿：上次儲存 …、已處理 n／N 處」，從上次的地方繼續。校稿進度存在輸出資料夾的 `.proofread` 裡，資料夾搬家也能接續。

## 定稿的步驟

1. 側欄切到「定稿」，看處理進度。
2. 按「**定稿…**」→ 出現確認畫面，列出要寫的檔（`transcript.final.md`、`transcript.final.srt`）與備份方式。這時還沒寫任何檔。
3. 按「定稿」→ 結果畫面列出實際寫入的檔、段數與字幕條數。按「開啟資料夾」可以直接看檔案。
4. 還有未處理的標記時，要先勾「仍要定稿」：校正與用字統一照建議，待確認寫成「原文〔?推測〕」。

定稿後，同一個分頁可以接著做：

- **名詞寫法同步**：勾選要套用的寫法 → 按「同步勾選的寫法…」→ 確認畫面 → 結果畫面。只改會議記錄或筆記裡的名詞寫法，先備份。
- **用定稿重做會議記錄**（要花費，需要 Pro 2.3.0 以上，[本機限定](#本機限定的稿)的稿不能用）：按「重做會議記錄…（要花費）」→ 確認畫面先寫出供應商、模型與預估費用 → 按「重做（要花費）」才執行。在背景整理，可以繼續校稿；完成後跳出結果與實際費用。

## 匯入對照表與詞表的步驟

1. 側欄切到「經驗整理」，看「對照表建議」與「詞表建議」。每一項都寫了次數與原因；符合條件的已經勾好。
2. 照你的判斷增減勾選。一次性的口誤不要勾，否則之後每一場都會被「改」成錯的。
3. 按「匯入勾選的項目…」→ 確認畫面列出要加幾筆、先備份到哪裡。
4. 按「匯入（先備份）」→ 結果畫面寫出實際加入的筆數與備份檔名。**下次轉寫時生效**。
5. 想撤銷：按「復原上次匯入」（匯入後兩個檔沒有再被改過時才能復原）。

## 本機限定的稿

用 Pro 2.4 的「會議轉寫（Pro，本機限定）」轉寫的那一份（輸出資料夾有 `local-only.json`），或 Pro 設定了整部電腦本機限定時（1.1.0 起）；1.1.1 起 Pro 的 `config.json` 讀不了或值看不懂時也是（說明列寫「本機限定（meeting-minutes-pro 的 config.json 讀不了或值看不懂，為了不外送已當成本機限定；…）」，首頁標題旁寫「本機限定（config.json 讀不了）」）：

1. 開啟方式相同：對輸出資料夾按右鍵 →「傳送到」→「會議記錄校稿」。
2. 頁首檔名旁有「**本機限定**」標示，上方一行說明「本機限定：這份不送 GPT 或 Claude。人工修改、定稿、經驗匯入照常；「用定稿重做會議記錄」停用。」
3. 這種稿通常沒有 AI 校正版，畫面上沒有標記：直接**選取錯字 → 按「✎ 修改選取文字（E）」**改寫，一路改完。
4. 側欄切到「定稿」→「定稿…」→「定稿」，得到 `transcript.final.md` 與 `transcript.final.srt`。
5. 「經驗整理」裡勾選常錯的詞 → 匯入對照表與詞表，下一次轉寫更準。
6. 「重做會議記錄…（要花費）」是灰的，下面寫「目前不能用：本機限定（…）」與怎麼解除；這是設計如此（那一步會把內容送給 AI）。

確定這一份可以送雲端了，才刪掉輸出資料夾裡的 `local-only.json`，重新整理頁面後重做就能用。見[本機限定](/features/local-only)。

## 同時校好幾份

- 每份稿一個分頁，可以同時開好幾份；首頁列出開著的稿與最近的稿。
- 同一份稿再開一次，**不會**出現第二個能修改的分頁：新分頁顯示「這份稿已經在另一個分頁開啟」，原分頁的標題閃爍提醒你切過去；也可以在新分頁按「改在這個分頁編輯」，原分頁會改成只能看（修改都已存檔）。

## 常見問題

**瀏覽器沒有自動開？**
再從右鍵開一次。還是沒有的話，檢查 Windows「設定 → 應用程式 → 預設應用程式」的網頁瀏覽器有沒有設定。

**顯示「請從右鍵或捷徑開啟」？**
校稿頁的網址只能用一次，不能加書籤或複製到別的瀏覽器。請從右鍵「傳送到」或雙擊「會議記錄校稿.mmproof」重新開啟。

**顯示「這份稿已在另一個分頁開啟」？**
同一份稿同時只能在一個分頁修改。切到原本的分頁（標題會閃爍），或按「改在這個分頁編輯」。

**「校正版逐字稿在上次校稿之後被重新產生」是什麼意思？**
你在校稿之後又用 Pro 重新轉寫或重跑了 AI 校正，`transcript.corrected.md` 和開始校稿時不同。這時畫面先顯示開始校稿時的版本（只能看），並給兩個選擇：「用新版重新開始，帶入對得上的決定」（對得上的標記沿用你的決定），或「用新版重新開始」。舊的校稿進度會先備份。

**儲存失敗怎麼辦？**
看頂端紅色提示寫的原因。修改還在分頁裡，不要關分頁；排除原因（例如把資料夾搬到可寫入的位置後重新開啟）或等自動重試。

**怎麼關掉？**
關分頁就好。所有分頁關掉約 3 分鐘後，背後的服務會自動結束。

**影片的畫面擋到要看的字？**
把影片視窗拖到別的地方、從左上角拉小，或按 `−` 收成右下角的「▶ 影片」標籤（聲音照常）。位置與大小會記住（見[影片視窗](#video)）。

**影片視窗寫「瀏覽器不能顯示這個影片的畫面」？**
瀏覽器解不了這個影片的畫面格式（例如部分 `.mov`），聲音照常從下方的播放列播放，時間碼點播也照常。要看畫面，可以先把影片轉成 `.mp4`（H.264）放在原位、同檔名。

**能在手機上校稿嗎？**
不行。視窗寬度小於 760px 時只能檢視、不能修改。

**會上傳逐字稿嗎？**
不會。服務只接受這部電腦本身的連線，頁面不連任何外部網站。只有你按「用定稿重做會議記錄」並確認時，定稿逐字稿才會送到 Pro 設定的 AI 供應商（與 Pro 整理會議記錄時相同）；[本機限定](#本機限定的稿)的稿連這一步都停用。

**「重做會議記錄」是灰的，寫「本機限定」？**
這一份是本機限定（輸出資料夾有 `local-only.json`、Pro 的 `config.json` 設了 `privacy.local_only: true`，或 1.1.1 起 Pro 的 `config.json` 讀不了或值看不懂），重做會把內容送給 AI，所以停用。按鈕下的原因會寫是哪一種與怎麼解除；`config.json` 讀不了時照原因修好它（見[本機限定 › config.json 讀不了或值看不懂](/features/local-only#config-unreadable)）。見[本機限定的稿](#本機限定的稿)。
