# 右鍵「傳送到」與拖放

**這頁幫你做到**：不用打任何指令，從檔案總管或 Finder 直接把錄音轉成逐字稿與會議記錄。

## 開始

- **Windows**：在檔案總管對錄音或錄影檔按右鍵 →「**傳送到**」→「**會議轉寫（Pro）**」。
  - Windows 11 沒看到「傳送到」：先點「顯示其他選項」，或按住 Shift 再按右鍵。
  - 可以一次選好幾個檔，題目只問一次，套用到全部檔案。
- **macOS**：把錄音或錄影檔**拖到「應用程式」裡的「會議轉寫（Pro）」**圖示上，或在 Finder 按右鍵 →「打開檔案的應用程式」→「會議轉寫（Pro）」。
  - 第一次使用時，macOS 會問是否允許它控制「終端機」，請按允許。

接著會打開一個視窗，依序問下面幾題。**每一題都可以直接按 Enter 用預設值**。

::: tip 機敏會議：用「會議轉寫（Pro，本機限定）」
2.4 起，「傳送到」選單（macOS 的「應用程式」）裡還有第二個入口「**會議轉寫（Pro，本機限定）**」。從這裡轉寫的那一份，什麼都不送 GPT 或 Claude，轉寫完也不問 AI。見下面的[本機限定的入口](#本機限定的入口)。
:::

## 轉寫前的題目

```text
內容類型（Enter＝會議）
  1 會議（含業務／客戶會議）       2 課程（含演講／專題分享）       3 訪談節目（Podcast、專訪）
  4 操作教學／示範                 5 座談／論壇／研討會             6 腦力激盪／工作坊／回顧
  7 客戶／需求訪談
  8 示範專案週會［自訂：會議］
請選擇：
講者人數（Enter＝自動判斷；填實際人數，不確定就留空；輸入 s＝略過說話者分離）：
本次專有名詞，逗號分隔（可留空）：
```

| 題目 | 意思 | 建議答法 |
|---|---|---|
| 內容類型 | 要整理成什麼樣的筆記（[7 種內容類型](/features/content-types)） | 會議直接按 Enter；之後會記住上次的選擇。自訂範本也會出現在這裡 |
| 講者人數 | 錄音裡有幾個人說話（[說話者分離](/features/diarization)） | 確定就填實際人數；不確定就按 Enter；只有一個人講話可以輸入 `s` 略過 |
| 本次專有名詞 | 這場會議會出現的人名、產品名，幫助辨識 | 有就填，逗號分隔，例如 `範例科技, DemoCRM`；常用的詞放進[專有名詞清單](/features/accuracy#專有名詞清單)就不必每次填 |
| 是否使用 Breeze | 有安裝 Breeze-ASR-25 才問 | 中英夾雜很多的技術會議選是；一般會議用預設比較快 |

然後開始轉寫。一小時的錄音通常要幾分鐘到十幾分鐘，依你的電腦而定。

## 轉寫完成後的題目

```text
AI 校正：GPT gpt-6.1-sol（產出 transcript.corrected.md，原稿不改）：約 9 分鐘、API 等價約 US$0.46～0.60（截圖整理另約 15～30 秒）；逐字稿文字、截圖 5 張、會議文件 2 份的名詞與段落會送到 GPT（OpenAI）
要做 AI 校正嗎？[Y/n]
```

```text
會議摘要：GPT gpt-6.1-sol（依校正版逐字稿整理）：約 8～10 分鐘、API 等價約 US$0.29～0.44；逐字稿文字、會議文件 2 份的名詞與段落、背景說明、校正時整理的參考資料（不含截圖）會送到 GPT（OpenAI）
要產生會議摘要嗎？[Y/n]
```

| 題目 | 意思 | 建議答法 |
|---|---|---|
| 要做 AI 校正嗎？ | 讓 AI 修正錯字、產出校正版逐字稿（[AI 校正](/features/ai-correction#ai-校正)） | 一般會議按 Enter（是）。含個資、不能送雲端的錄音輸入 `n`；這種會議下次直接用[本機限定的入口](#本機限定的入口)，就不會被問到 |
| 要產生會議摘要嗎？ | 讓 AI 整理出會議記錄（類型不是會議時，會改問「要產生課程筆記嗎？」這類題目） | 想直接拿到會議記錄就按 Enter（是） |
| 背景說明（一行） | 2.2 起，回答「是」之後、而且錄音旁沒有說明檔時才問：輸入會議名稱、與會者全名，幫 AI 補上姓名與日期（[參考資料](/features/reference#背景說明)） | 直接按 Enter 跳過也可以 |
| 用哪個模型？ | 回答「是」之後才問，列出可用的模型、預估時間與費用（例：`[Enter] 預設（GPT gpt-6.1-sol）`、`[2] Claude opus`、`[3] Claude sonnet`） | 按 Enter 用預設（有已登入的 Codex 時是 GPT，否則是 Claude opus）；想快一點可以選 Claude sonnet |

- 每一題都寫明這次要送什麼、送到哪一家：逐字稿文字一定有；錄影做 AI 校正時另有**影片截圖**（最多 8 張，縮小後），有放背景說明或會議文件時也會列出。**音檔與文件原檔不會送出**；會議摘要不送截圖。不想送截圖：`config.json` 的 `reference.frames` 改成 `false`（見[參考資料](/features/reference#怎麼關)）。
- 錄音超過 2 小時時，說明會變成黃色的 ⚠ 提醒，寫明比較長的時間與費用。
- 找不到 `claude` 或 `codex` 指令（或沒登入）時，這兩題都不問，結束畫面會寫怎麼安裝、登入，以及之後怎麼補做。
- 轉寫或 AI 處理要等好幾分鐘，這段時間不小心按到 Enter 也沒關係：每一題出現前會先清掉之前的按鍵。

## 本機限定的入口

機敏會議（客戶個資、合約、人事、未公開的資料）請用第二個入口，這一份**什麼都不送** GPT 或 Claude（2.4 起，[本機限定](/features/local-only)）：

- **Windows**：右鍵 →「傳送到」→「**會議轉寫（Pro，本機限定）**」。
- **macOS**：拖到「應用程式」裡的「**會議轉寫（Pro，本機限定）**」（Mac 上尚未實測）。

轉寫前的題目（內容類型、講者人數、專有名詞、Breeze）和一般入口相同。不同的是：

- 視窗標題與第一行是「會議轉寫（Pro，本機限定）」，開頭一行黃字：

  ```text
  本機限定（本機限定的右鍵入口）：這次不會把任何資料送到 GPT 或 Claude；轉寫與字幕都在這部電腦完成，不做 AI 校正與整理
  ```

- **不偵測** `claude`／`codex`，轉寫完**不問** AI 校正、會議摘要與背景說明。
- 輸出資料夾多一個標記檔 `local-only.json`。之後這一份的 AI 步驟一律拒絕（也包括用一般入口重轉、或在命令列執行），會議記錄校稿也會標示「本機限定」。
- 結束畫面：

  ```text
  本機限定：沒有送出任何資料（沒有 AI 校正，也沒有 AI 整理）。
  下一步：要人工校稿，對這個輸出資料夾按右鍵 → 傳送到 → 會議記錄校稿（Pro 的附屬工具，另外安裝）；校稿得到的經驗匯入對照表與詞表後，下次轉寫更準。
  要解除本機限定（之後才能用 AI 校正與整理）：這一份：刪除輸出資料夾裡的 local-only.json
  ```

整部電腦都不送（`config.json` 的 `privacy.local_only` 是 `true`）時，一般入口「會議轉寫（Pro）」也照這個方式走，開頭寫「本機限定（config.json 的 privacy.local_only）」。

## 結束畫面

列出產出的檔案（與字幕條數）、log 的位置與下一步，輸出資料夾會自動打開。可能多出的提醒：

- 黃字「說話者分離改用 CPU」：GPU 說話者分離這次沒用上，後面寫原因。
- 有發言很少的講者：提醒你可能是分離誤判（見[零星講者的 ⚠](/features/diarization#零星講者的-⚠)）。

最後停在「按 Enter 關閉」。

## 輸出資料夾裡有什麼

錄音檔旁邊的 `<檔名>_minutes/` 資料夾：

| 檔案 | 用途 |
|---|---|
| `transcript.md` | 閱讀用逐字稿，含時間碼、講者和畫面標記。交給 AI 校正與整理的就是這個 |
| `transcript.json` | 結構化逐字稿（給程式用），保留辨識原文 |
| `transcript.srt` | 字幕檔，一段一條 |
| `transcript.cues.srt` | 照字幕規則切條的字幕（不經 AI） |
| `local-only.json` | 本機限定標記（2.4，從本機限定入口轉寫時）：有這個檔，這一份就不送 GPT 或 Claude；刪掉＝解除（[本機限定](/features/local-only#marker)） |
| `transcript.corrected.md` | 校正版逐字稿（有做 AI 校正時） |
| `transcript.corrected.srt` | 校正版字幕（有做 AI 校正時） |
| `corrections.suggested.tsv` | 建議加進對照表的項目，**還沒生效**，確認後才加入 |
| `meeting-minutes.md` | 會議記錄（會議類型、有做會議摘要時），表頭寫「未經人工確認」 |
| `meeting-minutes.html`、`notes.html` | 會議記錄或筆記的[網頁版](/features/web)（2.1），用瀏覽器打開；找得到原始錄音時時間碼可點播放 |
| `notes.md`、`notes.json` | 課程、訪談等類型的筆記與它的結構化資料 |
| `frames/frame_0003_001523.jpg` | 影片截圖，檔名裡的 `001523` 代表 00:15:23 |
| `reference.json` | 參考資料整理（2.2）：AI 從截圖、文件認出的與會者、講者對應、會議日期與名詞（[參考資料](/features/reference)） |
| `context.md` | 入口輸入的背景說明（2.2），重跑時沿用 |
| `auto_correct.json`、`auto_minutes.json` | AI 校正與會議摘要的執行紀錄（不含逐字稿內容與金鑰） |
| `run_log.jsonl` | 這一場的[執行 log](/features/run-log) |

重新執行 AI 校正或會議摘要時，舊的結果會先改名成 `….<日期時間>.bak.md` 保留。

## 下一步

- 有 `meeting-minutes.md`：打開 `meeting-minutes.html`（用瀏覽器），確認決議與待辦，點時間碼可以回聽。要補講者姓名或修改，把它和 `transcript.corrected.md` 附到 Claude，說「**用 meeting-minutes-pro 檢查這份會議記錄**」（見 [Claude 桌面 App](/usage/claude-app)）。
- 有 `corrections.suggested.tsv`：看一下哪些建議是對的，加進[固定錯誤對照表](/features/accuracy#固定錯誤對照表)，下次會更準。
- 本機限定的那一份沒有會議記錄：用會議記錄校稿直接校 `transcript.md`、產生定稿逐字稿（見[本機限定 › 沒有 AI 摘要，怎麼整理](/features/local-only#no-ai-minutes)）。
- 接著校稿：對輸出資料夾按右鍵「傳送到 → 會議記錄校稿」，在瀏覽器裡逐處確認 AI 校正（見[用會議記錄校稿確認逐字稿](/usage/proofread)；要另外安裝[會議記錄校稿](/install/proofread)）。
