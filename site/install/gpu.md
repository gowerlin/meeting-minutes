# GPU 說話者分離（選用）

**這頁幫你做到**：決定要不要加裝 GPU 說話者分離，要裝的話照步驟裝好。

「說話者分離」是把逐字稿分成 S1、S2、S3…（第 1 位、第 2 位講者…）的步驟。不裝這個選項也完全能用：程式預設用 CPU 做說話者分離。

## 什麼時候值得裝

| 條件 | 說明 |
|---|---|
| 只適用 **Windows＋NVIDIA 顯示卡** | 驅動 570 以上、磁碟剩 8 GB 以上。macOS 沒有這個選項（Mac 沒有 NVIDIA 顯示卡） |
| 速度 | 每小時錄音約 1.5 分鐘（CPU 約 3.5 分鐘） |
| 準確度 | 在合成素材上，會議、課程、訪談 GPU 判得比較準；座談、工作坊則互有勝負（見[說話者分離與講者人數](/features/diarization#gpu-與-cpu-怎麼選)） |
| 空間 | 要下載約 5 GB（PyTorch 與 pyannote 套件），權重約 33 MB |
| 帳號 | 要一個免費的 Hugging Face 帳號，並同意模型作者的使用條件（[白話引導](/install/hugging-face)） |

常開多人會議、又有 NVIDIA 顯示卡：值得裝。只轉一對一的訪談或單人課程：不裝也沒差。

## 怎麼裝

**什麼時候會問**：安裝或升級時偵測到 NVIDIA 顯示卡、而且還沒裝過，安裝程式會先列出顯示卡、速度與要下載的大小，再問：

```text
是否安裝 GPU 說話者分離？[y/N]
```

直接按 Enter＝不裝。之後想裝，執行安裝資料夾裡的：

```powershell
install.cmd -GpuDiar
```

回答 y 之後，安裝程式會在同一個視窗一步一步帶你做：

1. 註冊或登入 Hugging Face。
2. 到模型頁面同意使用條件。
3. 建立一組「存取碼」（Access Token）。
4. 把存取碼貼進安裝程式。
5. 自動下載權重、用範例錄音實測一次。

每一步要做什麼、畫面上的英文是什麼意思，見 [Hugging Face 白話引導](/install/hugging-face)。安裝摘要寫「說話者分離：GPU（pyannote，可用…）」就是完成了。

## 裝失敗也沒關係

任何一步沒做完，**主程式照常裝好**，說話者分離照舊用 CPU，安裝摘要會寫原因。照原因補完之後，再執行一次 `install.cmd -GpuDiar`（已經裝好的部分不會重裝）：

| 安裝摘要寫的原因 | 意思 | 怎麼辦 |
|---|---|---|
| 還沒有登入 Hugging Face | 沒有貼存取碼，或貼得不完整 | 照引導第 3、4 步再做一次 |
| 還沒有在 Hugging Face 同意模型的使用條件 | 沒按同意，或剛按完、還沒生效 | 確認已按同意，過幾分鐘再試 |
| 權重下載失敗／權重檔不完整 | 網路中斷 | 確認網路後再試 |
| PyTorch 或 pyannote 安裝失敗／抓不到顯示卡 | 套件下載失敗或驅動有問題 | 看 `install.log`；更新顯示卡驅動後再試 |
| 顯示卡驅動太舊／磁碟空間不足／找不到 nvidia-smi | 不符合條件，沒有安裝 | 更新驅動或清出空間後再試 |
| 實測失敗 | 裝好了但跑不起來 | 看 `install.log`，回報問題 |

## 用起來是什麼樣子

- 裝好以後不用另外設定：顯示卡可用記憶體 ≥ 4 GB 時自動用 GPU，否則用 CPU。
- GPU 這次失敗（記憶體不足、逾時…）會自動改用 CPU，結束畫面會印原因。
- **座談類型預設用 CPU**：合成素材上，GPU 把只講了 11 秒的觀眾發言併掉了，CPU 反而分得對。
- 轉寫時不連網、不需要登入；本程式也關掉了 pyannote 的使用統計。

## 移除

```powershell
install.cmd -RemoveGpuDiar
```

會刪除 GPU 套件與權重，說話者分離改回 CPU。要順便登出 Hugging Face，見 [Hugging Face 白話引導](/install/hugging-face#登出)。
