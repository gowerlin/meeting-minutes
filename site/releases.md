# 更版紀錄

**這頁幫你做到**：知道每一版改了什麼、升級前要注意什麼。

- 公開 repo 只放最新版的程式；舊版的重點都寫在這頁。
- 首次公開發布的是 Pro **2.0.2** 與基本版 **1.0.1**；更早的版本沒有公開的 Release。
- 升級方式：重新執行新版的安裝程式（見[升級與解除安裝](/install/upgrade)）。

## meeting-minutes-pro（Pro 版）

### 2.4.1

2026-11-08 發布。**安全修正**，建議所有 2.4.0 的使用者升級（重新執行安裝程式即可，`config.json` 只更新版號）。

- **`config.json` 讀不了時也當成本機限定**：2.4.0 遇到 `config.json` 讀不了（手改時打錯逗號或引號、不是 UTF-8、開頭有 BOM、空檔、最外層不是 `{ … }`、沒有權限或被鎖住），會當成「沒有開全域本機限定」而照常把內容送到 GPT 或 Claude；`privacy.local_only` 寫成 `"true"`（有引號）、`1`、`null` 時也一樣當成沒開。2.4.1 起這些情況一律**當成本機限定**：入口不問 AI，`auto_correct.py`、`auto_minutes.py` exit 6，畫面寫明原因、檔案路徑與恢復方法（見[本機限定 › config.json 讀不了或值看不懂](/features/local-only#config-unreadable)）。不存在時照舊不是本機限定。
- **安裝程式不再蓋掉讀不了的 `config.json`**：2.4.0 重新安裝（或重新偵測硬體）時，會把讀不了的 `config.json` 整份換成預設值，連帶把 `privacy.local_only: true` 改回 `false`。2.4.1 起安裝程式、`setup_backend.py`、`setup_gpu_diar.py` 遇到讀不了的檔會停下、什麼都不寫，請修好或刪掉後重新執行。
- 其他設定（後端、詞表等）在讀不了時照舊用預設值，轉寫開頭多印一行警告。執行 log、`runs.jsonl` 的本機限定來源多一種值 `config-unreadable`（欄位不變）。在 Claude 對話中，skill 改用同一個判定，判定失敗也照本機限定處理。
- **影響範圍**：只有用**整部電腦的本機限定**（`config.json` 的 `privacy.local_only`）而且 `config.json` 讀不了或值寫錯的情況。用「會議轉寫（Pro，本機限定）」右鍵入口（標記檔 `local-only.json`）的那幾份不受影響。還沒升級前的做法：機敏會議改用本機限定的右鍵入口；或確認 `config.json` 用 UTF-8 存、`privacy.local_only` 寫 `true`（不加引號）。
- 用 Claude 桌面 App 的人請改上傳新版的上傳檔。會議記錄校稿建議一起升到 1.1.1。
- **已知限制**：macOS 的修正（安裝程式的檢查、拖放入口）沒有實機驗證。

### 2.4.0

這一版加入**本機限定**：機敏會議可以完全不送雲端（[本機限定](/features/local-only)）。

- **本機限定（機敏會議）**：兩種開法，任一成立就是本機限定。
  - **每份會議**：新的右鍵入口「**會議轉寫（Pro，本機限定）**」（macOS 是同名的 app）。從這裡轉寫的輸出資料夾會寫入標記檔 `local-only.json`，之後這一份的每一步都照本機限定處理。命令列是 `transcribe.py --local-only`。
  - **整部電腦**：`config.json` 的 `privacy.local_only` 改成 `true`。
  - 本機限定時，轉寫、字幕、網頁版、全文用字統一照常；入口**不問** AI 校正與整理（也不偵測 `claude`／`codex`），結束畫面寫「本機限定：沒有送出任何資料」並提示用會議記錄校稿人工校稿。
  - `auto_correct.py`、`auto_minutes.py`、`transcribe.py --correct` **拒絕送出**：exit 6、`reason: local_only`，訊息寫明為什麼與怎麼解除。**沒有任何旗標可以略過**：要解除只能刪標記檔或改設定。
  - [執行 log](/features/run-log) 多記 `privacy` 事件；本機限定時摘要多 `local_only`、`local_only_source` 兩欄（其他時候與 2.3.0 相同）。
  - 在 Claude 對話中，skill 遇到本機限定時，讀逐字稿之前會先提醒「在對話中讀逐字稿＝送到 Anthropic 雲端」並等你明確答應；不執行 AI 校正與整理的程式。
- **畫面上的供應商名稱改成 GPT／Claude**（GPT 在前）：例「AI 校正：GPT gpt-6.1-sol（…）；逐字稿文字會送到 GPT（OpenAI）」「[Enter] 預設（GPT gpt-6.1-sol）」，安裝程式寫「將使用：GPT（gpt-6.1-sol，透過 Codex）」。帳號、金鑰名、設定值（`openai`、`claude`）、旗標（`--openai`、`--claude`）照舊；輸出檔的表頭格式也不變（例「自動整理：OpenAI gpt-6.1-sol low，…」）。
- **說清楚 Claude 對話會上雲**：README 與 skill 改寫成「在 Claude 對話（Claude Code、Claude 桌面 App）中讀到的逐字稿與截圖會送到 Anthropic 雲端處理；對話中讀檔前沒有另外的送出確認；音檔不上傳」。
- **安裝程式**：建立與移除第二個右鍵入口（macOS 第二個 app）；安裝摘要多一行「本機限定：開／關」；升級時 `config.json` 補上 `privacy` 這一組設定（預設 `false`，你改過的值保留）。
- 從 2.3.x 升級只要重新執行安裝程式；詞表、對照表、GPU 與精度設定都保留。用 Claude 桌面 App 的人請改上傳新版的上傳檔。會議記錄校稿建議一起升到 1.1.0（才認得本機限定）。
- **已知限制**：macOS 的本機限定入口（第二個 app）沒有實機驗證。

### 2.3.0

這一版配合新的附屬工具[會議記錄校稿](/features/proofread)，讓「人工校好的逐字稿」可以直接拿來整理會議記錄。

- **用定稿整理會議記錄**：輸出資料夾裡有會議記錄校稿產生的定稿逐字稿 `transcript.final.md` 時，會議摘要改依據它整理。表頭寫「依據：`transcript.final.md`（已人工校稿）」，〈記錄來源〉寫「自動轉寫 + 人工校稿 + AI 自動整理」，網頁版也一樣。
  - 新參數 `auto_minutes.py --source final`（只用定稿）；預設 `--source auto` 的順序改成定稿 ＞ 校正版 ＞ 原稿。
  - 定稿比校正版舊（之後又重新轉寫或校正過）時不用它，改用校正版並印一行說明，避免會議記錄和目前的逐字稿對不上。
  - 沒有定稿時，結果與 2.2.0 完全相同。
- **先看費用再決定**：新參數 `auto_minutes.py --estimate-only`，不呼叫模型、不寫任何檔，算出這次會送多少字、用哪個供應商與模型、API 等價費用的區間。會議記錄校稿的「重做會議記錄」按鈕就是先用它顯示費用。
- **完成時寫出實際費用**：會議摘要完成時，結果裡多了這次的實際 API 等價費用（與[執行 log](/features/run-log) 的算法相同）。
- **解除安裝會一起移除會議記錄校稿**：裝了會議記錄校稿時，Pro 的解除安裝會先自動移除它（不詢問、保留最近的稿清單），再處理 Pro 自己的檔案，不會留下指向不存在檔案的右鍵選單與 `.mmproof` 開啟方式。升級 Pro 時不會動會議記錄校稿。
- **修正「本次專有名詞」含引號時被弄壞**：Windows 的右鍵入口在 Windows PowerShell 5.1 上，「本次專有名詞」含 `"` 或以 `\` 結尾時，傳給轉寫程式的內容會被弄壞；已修正（PowerShell 7 與 macOS 本來就正常）。
- 設定鍵、入口題目、輸出檔名都沒有變；從 2.2.x 升級只要重新執行安裝程式（`config.json` 只更新 `runtime_version`，你的設定與詞表保留）。用 Claude 桌面 App 的人請改上傳新版的上傳檔。
- **已知限制**：macOS 的解除安裝連動沒有實機驗證。

### 2.2.0

- **參考資料**：AI 校正與會議摘要會一起參考三種資料，補上逐字稿裡拿不到的資訊（與會者全名、講者對應、會議日期），人名與名詞也更準（[參考資料](/features/reference)）。
  - **影片截圖**：AI 校正時挑出最多 8 張（去掉空白與連續重複的畫面，縮到長邊 1280 px），一次送給「參考資料整理」；從截圖認出與會者名牌、正在發言的人、片頭的會議名稱與日期、簡報上的名詞。
  - **背景說明**：媒體旁放 `<主檔名>.context.md`（或 `.context.txt`）就會讀；沒有時，入口在你答應 AI 校正或摘要之後問**一行**描述（直接按 Enter 跳過），存成輸出資料夾的 `context.md`，重跑時沿用。
  - **會議文件**：PDF、PPTX、DOCX、TXT、MD，放在媒體旁（檔名以主檔名開頭）、媒體旁的 `refs` 資料夾（資料夾裡只有這一個錄音或錄影時），或輸出資料夾的 `refs` 資料夾。本機抽文字，只送挑出的名詞與相關段落，**不送原檔**。
  - 人名與名詞的寫法以參考資料為準，**內容（誰說了什麼、數字、決議、待辦）一律以逐字稿為準**；文件裡有、但會中沒有說的內容不會寫進會議記錄。
- **會議記錄補上與會者與日期**：〈與會者〉補上截圖對應到的姓名，後面標「（截圖）」；〈日期時間〉從截圖補上。校正版逐字稿的〈講者對應〉也填上姓名。結果另存成輸出資料夾的 `reference.json`，可以打開確認、手改後重跑摘要。
- **全文用字統一**：同一個英文名詞只差大小寫或空格／`.`／`-` 的寫法（例 `NotebookLM`、`notebooklm`、`notebook lm`），在校正版逐字稿、校正版字幕、會議記錄與筆記統一成一種；在本機處理，**不呼叫模型、不送任何資料**（[全文用字統一](/features/consistency)）。
- **送出的內容改變了**：
  - 做 AI 校正時，除了逐字稿文字，**影片截圖（最多 8 張，縮小後）會送到你選的供應商**，背景說明與會議文件的名詞和段落也會一起送出。
  - 做會議摘要時送逐字稿文字、背景說明與文件的名詞和段落；**摘要不送截圖**，只用校正時從截圖整理出的文字結果。
  - 音檔與文件原檔仍然不上傳。詢問行會寫明這次要送幾張截圖、幾份文件。
  - **不要送截圖**：`config.json` 的 `reference.frames` 改成 `false`（單次：`--no-frames`）。之前「音檔與截圖不會送出」的說法已全部改正。
- **新的旗標與設定鍵**：
  - 旗標：`--context "<一行>"`、`--refs <檔或資料夾>`、`--no-refs`、`--no-context`、`--no-frames`。
  - 設定鍵：`config.json` 新增 `reference` 區塊（`frames`、`max_frames`、`frame_max_px`、`docs`、`context`、`ask_context` 與各項上限）與 `consistency.enabled`，預設全部開啟。
  - 新指令：`refs.py plan`、`refs.py show`（查看會用到的參考資料，不呼叫模型）、`consistency.py`（對已經有的輸出資料夾做用字統一）。見[手動執行與參數](/usage/advanced)。
- **新套件 `pypdf`**（BSD-3-Clause，純 Python）：讀 PDF 用，升級時由安裝程式自動安裝。DOCX、PPTX 用 Python 標準函式庫讀。
- **已知限制**：掃描檔（沒有文字層的 PDF）與加密的 PDF 不會讀（略過、其餘照常）；`.doc`、`.ppt`、`.xlsx` 與圖片檔不讀。macOS 的入口（背景說明一行與詢問行）沒有實機驗證；Anthropic 與 OpenAI 的 API 通道送圖沒有用真的金鑰實測。
- 既有的輸出檔、設定鍵、旗標與入口題目都保留；入口只多一題背景說明（答應 AI 步驟、而且沒有說明檔時才問）。從 2.1.x 升級只要重新執行安裝程式（`config.json` 會補上 `reference`、`consistency` 區塊，你的設定與詞表保留）。

### 2.1.0

- **會議記錄網頁版**：整理完會議記錄或筆記時，同一個輸出資料夾多一份 `meeting-minutes.html`（其他類型 `notes.html`），用瀏覽器打開：左側目錄、捲動時標示目前章節、深淺主題切換、會議的決議／待辦／待釐清問題摘要卡（[網頁版](/features/web)）。
- **時間碼點了播放**：找得到瀏覽器能播的原始錄音或影片時，頁面底部放一個播放器，內文的時間碼點了跳到那一秒播放；找不到或格式不能播時，時間碼是一般文字。
- **完全離線**：網頁版是單一個檔案，不連任何網站；由本機程式轉換，不呼叫任何模型。
- **預設產生，可以關**：入口不多問題目，結束畫面多列一行網頁版。`config.json` 新增 `html` 區塊（`enabled`、`media`、`theme`）；單次不產生用 `auto_minutes.py --no-html`。
- **補產生**：手改 `.md` 之後，用新指令 `render_html.py` 重新產生網頁版（Claude App 上傳用的 skill 也附了同一支程式）。
- **載入訊息改印實際模型名**：轉寫時的「載入」訊息改印實際載入的模型（例「Breeze-ASR-25 載入」「Whisper large-v3-turbo 載入」）。之前選 Breeze 時也寫成「Whisper 載入」，只是訊息寫錯，實際用的是 Breeze。
- **已知限制**：網頁版只在 Windows 的 Chrome（Edge 抽查）實測；macOS 的 Safari 沒有實機驗證，格式不能播時會自動收起播放器、時間碼變文字。
- 既有的輸出檔、設定鍵、旗標與入口題目都不變；從 2.0.x 升級只要重新執行安裝程式（`config.json` 會補上 `html` 區塊，你的設定與詞表保留）。

- **在瀏覽器裡逐處確認 AI 校正**：校正、待確認、用字統一三種標記一目了然，點一下選修正、原文或自由輸入；同樣的標記可以一起套用；鍵盤 `J`／`A`／`R`／`E` 就能一路校完。

- **定稿**：產出沒有任何標記的 `transcript.final.md` 與 `transcript.final.srt`（沿用 Pro 的字幕對時），不改原稿與校正版；定稿後可以把校稿確認的名詞寫法同步到會議記錄或筆記。
- **用定稿重做會議記錄**（選用、要花費，需要 Pro 2.3.0 以上）：先顯示供應商、模型與預估費用，確認後才在背景整理，完成時寫出實際費用。
- **經驗匯入**：從校稿結果整理出「原文 → 正確寫法」與新名詞，符合條件的預設勾選，匯入 Pro 的錯誤對照表與詞表（先備份、可以復原），下次轉寫就會自動改對。
- **一鍵開啟、多份同時**：Windows 右鍵「傳送到 → 會議記錄校稿」或雙擊資料夾裡的「會議記錄校稿.mmproof」；macOS 把資料夾拖到「會議記錄校稿.app」。可以同時開好幾份（每份一個分頁），同一份稿只能在一個分頁修改。
- **全部在本機**：只接受這部電腦本身的連線、不載入任何外部資源、防火牆不會跳出詢問；不多裝任何套件（用 Pro 的 Python）。
