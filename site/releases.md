# 更版紀錄

**這頁幫你做到**：知道每一版改了什麼、升級前要注意什麼。

- 公開 repo 只放最新版的程式；舊版的重點都寫在這頁。
- 首次公開發布的是 Pro **2.0.2** 與基本版 **1.0.1**；更早的版本沒有公開的 Release。
- 升級方式：重新執行新版的安裝程式（見[升級與解除安裝](/install/upgrade)）。

## meeting-minutes-pro（Pro 版）

### 2.0.2

- **範例改用虛構名稱**：README、skill 說明與參考文件裡的公司、人名、系統名與會議情境，都換成一看就知道是示範用的名字（例「星河物流」「王小明」）；固定錯誤對照表的範例改成「酷伯內蒂斯 → Kubernetes」。
- **預設詞表變短**：內附的預設 `glossary.txt` 只留說明與幾個通用技術詞（Kubernetes、PostgreSQL、Redis、API），預設 `corrections.tsv` 也改成示範用的內容。新安裝時給 Whisper 的提示詞跟著變短。
- **安裝不覆蓋你的詞表**：已經有 `glossary.txt`、`corrections.tsv` 時，安裝程式會保留，升級後你自己加的詞照舊。
- **自動校正的範例句**：自動校正給 AI 的說明裡，有一個「音近誤辨識」的範例句改用虛構名稱；規則與句型不變。
- **整理說明文字**：程式註解與文件裡的開發紀錄編號拿掉，改寫成功能開始的版號（例〔1.2.2〕）與實測說明。
- 程式行為、設定鍵、輸出檔都與 2.0.1 相同；從 2.0.1 升級只要重新執行安裝程式。

### 2.0.1

- 升級或新安裝後**第一次**用右鍵轉寫時，「內容類型」選單前不再出現一段紅字錯誤（只是還沒有「上次的選擇」，不影響結果）。
- 同一類寫法一併修正：Windows 全新安裝時，安裝程式也不再印同樣的紅字。

### 2.0.0

- **7 種內容類型**：會議以外，課程、訪談節目、操作教學、座談、工作坊、需求訪談各自整理成合適的筆記（[內容類型](/features/content-types)）。
- **自訂範本**：在 `templates` 資料夾放自己的範本（[自訂範本](/features/custom-templates)）。
- **字幕**：新增照字幕規則切條的 `transcript.cues.srt`，以及 AI 校正後的 `transcript.corrected.srt`（[字幕](/features/subtitles)）。
- **說話者分離改進**：講者人數改成「保留發言最多的 N 位」、發言很少的代號標 ⚠、分群門檻依類型；輸入 `s` 可以略過說話者分離（[說話者分離](/features/diarization)）。
- **GPU 說話者分離（選用）**：有 NVIDIA 顯示卡可以選裝，附 Hugging Face 白話引導（[GPU 說話者分離](/install/gpu)）。
- 升級前請看[從 1.x 升級到 2.0 要注意的事](/install/upgrade#從-1-x-升級到-2-0-要注意的事)。

### 1.2.2

- 每一題出現前先清掉處理中誤按的按鍵：等待時不小心按到 Enter，不會誤答下一題，也不會讓視窗直接關閉。
- 會議摘要的「待釐清問題」更嚴格：會中已經有答覆、只是說明現況、沒有人問的事都不列。
- 畫面與檔案上的分段數一律寫「段」。
- 安裝畫面：升級時寫「升級中」，並列出補了哪些設定鍵。

### 1.2.1

- 長會議分段整理時，每段附上前後段的幾句話當上下文，段落交界的討論不會再被誤列成待釐清問題。
- 會議記錄的待辦表多一欄「時間碼」。
- 會議摘要的選模型選單把 Claude `sonnet` 標成「較快」。
- 指定後端重新安裝時，沿用原本的精度設定。

### 1.2.0

- **會議摘要（選用）**：程式直接呼叫 Claude 或 OpenAI 整理出 `meeting-minutes.md`；長會議分段整理再彙整。
- **執行 log**：每次轉寫記下各步驟的時間、模型呼叫的 token 與 API 等價費用，可以彙整成表（[執行 log](/features/run-log)）。
- 右鍵與拖放入口改在**逐字稿完成後**依序問「要做 AI 校正嗎？」「要產生會議摘要嗎？」，並附預估時間與費用。

### 1.1.0

- **本機分段標點**：轉寫時就在本機依講者、停頓與段長分段，補上標點。
- **OpenCC 詞彙回復表**：不讓簡繁轉換把「權限」「帳號」改成「許可權」「賬號」。
- **自動校正（選用）**：轉寫後自動呼叫 Claude 或 OpenAI 校正同音錯字與專有名詞，產出校正版逐字稿與對照表建議。

### 1.0.0

- Pro 版第一版：在基本版之外，多了**固定錯誤對照表**、**校正版逐字稿**、**Breeze-ASR-25**（選裝）。
- 有自己的 skill 名稱、資料夾與右鍵入口，可以和基本版同時安裝。

## meeting-minutes（基本版）

### 1.0.1

- **範例改用虛構名稱**：README、skill 與預設 `glossary.txt` 的範例改用虛構的公司名、人名與通用技術詞；預設 `glossary.txt` 只有幾個通用技術詞。安裝程式不會覆蓋已經存在的 `glossary.txt`，升級後你自己加的詞都會保留。
- **與 Pro 版的差異**：README 新增這一節，列出兩版的功能差異，以及同時安裝時各自的 skill 名稱、資料夾、入口與環境變數。
- **第三方元件聲明**：新增 `THIRD-PARTY-NOTICES.md`，安裝時也會複製到 runtime 資料夾。
- **讀設定檔不印紅字**：右鍵「傳送到 → 會議轉寫（基本版）」與安裝程式讀 `config.json` 時，找不到檔案或內容壞掉都安靜略過，不會在主控台印出紅字錯誤（比照 Pro 2.0.1）。
- **版號**：README、skill 與安裝程式都寫上版號並保持一致，安裝畫面與安裝紀錄會印出版號。
- **相依套件**：`huggingface_hub` 加上版本上限 `<3`（與 Pro 版相同），避免日後的大改版讓模型下載失敗。
- **測試用安裝位置**（給開發者）：安裝程式新增 `-TestRoot`（macOS `--test-root`），可以裝到指定資料夾試用，不影響正式安裝。
- 功能、輸出檔、`config.json` 都與 1.0.0 相同；從 1.0.0 升級只要重新執行安裝程式。

### 1.0.0

- 第一版：本機轉寫（Whisper large-v3-turbo，安裝時自動選硬體）、說話者分離、影片截圖、繁體輸出、專有名詞提示、幻覺過濾，以及在 Claude 裡整理成會議記錄。
