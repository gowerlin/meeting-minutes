# 功能總覽

**這頁幫你做到**：一眼看懂 Pro 版會做哪些事，再點進想深入的功能。

## 轉寫時在你的電腦上做的事

這些步驟全在本機完成，不連網、不送出任何資料。

| 功能 | 一句話說明 |
|---|---|
| 本機語音辨識 | 用 Whisper large-v3-turbo 把語音轉成文字；安裝時自動挑出你電腦上最快的硬體（Intel NPU／GPU、NVIDIA、Apple Silicon 或 CPU） |
| [說話者分離](/features/diarization) | 把逐字稿分成 S1、S2…（第幾位講者）；可以填人數，也可以略過；有 NVIDIA 顯示卡可以選裝 GPU 版 |
| 影片截圖 | 影片偵測到畫面變化（簡報翻頁、切換共享畫面）就自動截圖，檔名帶時間碼 |
| 繁體輸出 | 轉成台灣用語的繁體中文，並避免把「權限」「帳號」轉成「許可權」「賬號」（[OpenCC 詞彙回復表](/features/accuracy#opencc-詞彙回復表)） |
| 本機分段標點 | 依講者切換、停頓與段落長度分段，並補上標點 |
| 幻覺過濾 | 刪掉語音辨識常見的幻覺句（例如「字幕由…提供」）、壓縮跳針重複的字 |
| [固定錯誤對照表](/features/accuracy#固定錯誤對照表) | 總是聽錯的詞記成一張表，之後轉寫自動替換，越用越準 |
| [專有名詞清單](/features/accuracy#專有名詞清單) | 事先告訴辨識模型會出現哪些人名、產品名，提高辨識正確率 |
| [Breeze-ASR-25](/features/accuracy#breeze-asr-25)（選裝） | 對台灣華語與中英夾雜特別準的辨識模型，速度較慢 |
| [字幕](/features/subtitles) | 依字幕規則重新切條的 `.srt` 字幕，可以搭配影片回放 |

## 轉寫完成後，選用的 AI 步驟

每次轉寫完都會問你要不要做；做的話，逐字稿文字會送到你選的供應商（Claude 或 OpenAI）。AI 校正另外送影片截圖（最多 8 張，縮小後）、背景說明與會議文件的名詞和段落；會議摘要送逐字稿文字、背景說明與文件的名詞和段落，**不送截圖**。音檔與文件原檔都不送。詢問行會寫明這次要送什麼（見[參考資料](/features/reference)）。

| 功能 | 一句話說明 |
|---|---|
| [AI 校正](/features/ai-correction#ai-校正) | 修正同音錯字與專有名詞，產出標出每一處修改的校正版逐字稿；原始逐字稿一字不改 |
| [會議摘要](/features/ai-correction#會議摘要) | 整理出摘要、議題、決議、待辦、待釐清問題，每一項附時間碼 |
| [7 種內容類型](/features/content-types) | 會議以外，課程、訪談節目、操作教學、座談、工作坊、需求訪談各自整理成合適的筆記 |
| [自訂範本](/features/custom-templates) | 延伸內建類型，例如改節標題、補一段「整理重點」 |
| [網頁版](/features/web) | 整理完同時產生 `.html`：左側目錄、深淺主題、時間碼點了播放原始錄音；單一檔、完全離線，由本機程式轉換、不呼叫模型 |
| [參考資料](/features/reference) | AI 校正與摘要一起參考影片截圖、背景說明與會議文件（PDF、PPTX、DOCX），補上與會者全名、講者對應與會議日期 |
| [全文用字統一](/features/consistency) | 同一個英文名詞只差大小寫或空格的寫法統一成一種；本機處理、不呼叫模型 |

## 記錄與管理

| 功能 | 一句話說明 |
|---|---|
| [執行 log 與費用](/features/run-log) | 每次轉寫記下各步驟的時間、模型呼叫的 token 與 API 等價費用，可以彙整成表 |
| 對照表條件式自動寫入（選用，預設關） | 同一個修正在好幾場會議都出現時，自動加進對照表（見[提升準確度](/features/accuracy#對照表自動寫入-選用-預設關)） |

## 和基本版相比

Pro 版多了：固定錯誤對照表、校正版逐字稿、Breeze-ASR-25、本機分段標點、OpenCC 詞彙回復表、自動 AI 校正、自動會議摘要、執行 log、7 種內容類型、自訂範本、字幕、網頁版、參考資料、全文用字統一、說話者分離改進（含 GPU 選項）。差異表見[基本版](/basic#和-pro-版的差異)。
