# 網頁版

**這頁幫你做到**：用瀏覽器看會議記錄，點時間碼直接回聽那一段。

2.1 起，整理完會議記錄或筆記時，輸出資料夾裡多一份 `.html`，用 Chrome、Edge 等瀏覽器直接打開即可。

![會議記錄網頁版：左側目錄、頁首的決議／待辦／待釐清問題摘要卡、底部的原始錄音播放列](/web-version-meeting.png)

*以合成素材（自寫、虛構的會議講稿）產生的範例畫面。*

## 哪一份會有網頁版

| 來源 | 網頁版 |
|---|---|
| `meeting-minutes.md`（會議，含延伸會議的自訂範本） | `meeting-minutes.html` |
| `notes.md`（其他 6 種內容類型與它們的自訂範本） | `notes.html` |

- 預設開啟：入口（右鍵「傳送到」、拖放）做了會議摘要，或執行 `auto_minutes.py` 時，寫完 `.md` 就接著產生。入口**不多問題目**，結束畫面多列一行網頁版，「下一步」改成用瀏覽器打開它。
- 網頁版是 `.md` 的**衍生檔**，內容以 `.md` 為準，不能在網頁上編輯。

## 頁面上有什麼

- **目錄**：左側列出每一節（螢幕寬度小於 1024px 時收成頂端的「目錄」列），捲動時標示目前讀到哪一節。
- **頁首**：標題、日期、與會者或講者，以及「自動整理｜未經人工確認」（或「經對話確認」）的標示。
- **摘要卡**（會議才有）：決議、待辦、待釐清問題各幾項，點了跳到那一節。
- **深淺主題**：預設深色，頁首的按鈕可以改成淺色，瀏覽器會記住你的選擇。
- **列印**：不印目錄與播放列，時間碼印成文字。

## 時間碼點了播放

找得到瀏覽器能播的原始錄音或影片時，頁面底部（影片在桌機是右下角的小窗）放一個播放器，內文的 `HH:MM:SS` 變成按鈕，點了跳到那一秒開始播放。鍵盤也可以：Tab 移到時間碼，按 Enter。

原始檔依序這樣找，第一個能播的就用：

1. 輸出資料夾的上一層、與原始檔同名（轉寫時預設就是這樣：`週會.m4a` 旁邊的 `週會_minutes/`）。
2. 輸出資料夾裡、與原始檔同名（把原始檔搬進 `_minutes` 資料夾一起保存）。
3. 上一層、名稱相同但副檔名不同的可播放檔（例 `.mov` 另存成 `.mp4`）。

| 副檔名 | 處理 |
|---|---|
| `.mp3` `.m4a` `.aac` `.wav` `.flac`、`.mp4` `.m4v` | 放播放器 |
| `.ogg` `.opus` `.webm`、`.mov` 等 | 放播放器；瀏覽器不能播時，開頁時自動收起、時間碼變文字 |
| `.wma` `.wmv` `.avi` `.mkv` 等 | 不放播放器，頁首寫明這個格式瀏覽器多半不能播，時間碼以文字顯示 |

### 搬動或轉寄時

- 網頁版寫的是**相對路徑**（例 `../週會.m4a`），不寫你的資料夾或使用者名稱。
- 原始檔和 `_minutes` 資料夾**一起搬**（或把上一層資料夾整個壓縮、複製）時照樣能播。
- 只搬 `_minutes` 資料夾、原始檔改了名，或只把 `.html` 傳給別人時，開頁時讀不到媒體，播放器自動收起、時間碼變回文字，頁面其他部分正常。
- 網頁版裡有整份會議記錄的內容，轉寄時的注意事項和 `.md` 相同。

## 完全離線

- 單一個 `.html` 檔，樣式與程式都在檔案裡、用系統字型，不連任何網站。頁面設定了 Content-Security-Policy，就算內容裡混進連外的東西，瀏覽器也會擋下。
- 轉換在你的電腦上由程式完成，**不呼叫任何模型**、不花費用，產生不到 1 秒。

## 改過 `.md` 之後重新產生

在 Claude 對話中改了會議記錄，Claude 會自己重新產生。你自己手改 `.md` 時，執行：

```powershell
& "$MMH\venv\Scripts\python.exe" "$MMH\scripts\render_html.py" "<檔名>_minutes"
```

```bash
"$MMH/venv/bin/python" "$MMH/scripts/render_html.py" "<檔名>_minutes"
```

| 參數 | 作用 |
|---|---|
| `--file notes.md` | 轉輸出資料夾內指定的 `.md`（例備份檔） |
| `--media "<錄音或影片>"`／`--no-media` | 指定原始媒體／不放播放器 |
| `--md "<檔案>.md" [--out "<檔案>.html"]` | 沒有輸出資料夾的單獨一份 `.md`（不找媒體） |
| `--theme dark\|light` | 第一次開啟時的主題 |

已有同名 `.html` 時直接覆寫。改過 `notes.json` 執行 `auto_minutes.py --render-only` 時會自動接著產生網頁版，不必另外執行。

## 設定

`config.json` 的 `html`（升級時自動補上）：

| 鍵 | 預設 | 說明 |
|---|---|---|
| `html.enabled` | `true` | 寫完 `.md` 後產生網頁版；`false`＝不產生。單次不產生：`auto_minutes.py --no-html` |
| `html.media` | `auto` | `auto`＝找原始媒體並放播放器；`off`＝不放播放器（時間碼一律文字） |
| `html.theme` | `dark` | 第一次開啟時的主題（`dark`／`light`） |

網頁版產生失敗**不影響** `.md` 與整理結果：畫面印一行「網頁版未產生（原因）；可執行 render_html.py 補做」。

## Claude 桌面 App

上傳用的 skill 附了同一支轉換程式。Claude 在 App 寫完會議記錄後會問要不要順便產生網頁版，產生後當成檔案交給你。App 的沙盒裡沒有原始錄音，所以時間碼是文字；要點了播放，把 `.md` 放回你電腦上的 `<檔名>_minutes` 資料夾，再執行上面的 `render_html.py`。

## 已知限制

- 只在 Windows 的 Chrome（Edge 抽查）實測過 `.mp3`、`.wav`、`.mp4`；**macOS 的 Safari 沒有實機驗證**，格式不能播時靠「自動收起播放器、時間碼變文字」兜底。
- 逐字稿（`transcript.md`）與基本版目前沒有網頁版。
- 外部網址顯示成文字，不做成可點的連結。

## 疑難排解

| 狀況 | 怎麼做 |
|---|---|
| 時間碼不能點 | 原始檔不在 `<檔名>_minutes` 的上一層（搬走、改名，或轉寫時用了 `--out-dir`），或格式瀏覽器多半不能播：執行 `render_html.py "<檔名>_minutes" --media "<原始檔或可播的檔案>"` |
| 網頁版內容和 `.md` 不一樣 | 改過 `.md` 之後沒有重新產生：執行 `render_html.py "<檔名>_minutes"` |
| 沒有產生網頁版 | 看 `auto_minutes.json` 的 `html.reason`：`disabled`＝設定關了或加了 `--no-html`；`template_missing`＝樣板不見了（重新執行安裝程式）；`write_failed`＝輸出資料夾不能寫入 |
| 不想要網頁版 | `html.enabled` 改成 `false`；只是不要播放器：`html.media` 改成 `off` |
