# AI 校正與會議摘要

**這頁幫你做到**：了解轉寫完成後那兩題「要做 AI 校正嗎？」「要產生會議摘要嗎？」在做什麼，決定要不要用、用哪個模型。

## 送出去的是什麼

| | 會不會送出 |
|---|---|
| 音檔、錄影 | ❌ 不會。轉寫全在你的電腦上 |
| 逐字稿**文字** | ⚠ 只在你回答「是」的時候，送到你選的那一家（Anthropic 的 Claude，或 OpenAI） |
| 影片截圖（2.2 起） | ⚠ **AI 校正**時送出最多 8 張（去掉空白與重複的畫面，縮到長邊 1280 px），用來認出與會者、會議日期與名詞。**會議摘要不送截圖**。不要送：`config.json` 的 `reference.frames` 改成 `false`（單次 `--no-frames`） |
| 背景說明、會議文件（2.2 起） | ⚠ 有放的話，AI 校正與會議摘要都會送背景說明全文，以及會議文件裡挑出的名詞與相關段落；**文件原檔不送**（見[參考資料](/features/reference)） |
| API 金鑰、帳號 | ❌ 不會寫進任何設定檔、log 或輸出檔；金鑰只從環境變數讀 |

每一題都會寫明這次要送什麼（例「逐字稿文字、截圖 5 張、會議文件 3 份的名詞與段落會送到 OpenAI」）、送到哪一家，並附這次的預估時間與費用。

- Claude：依 Anthropic 對你的帳號（訂閱）或 API 適用的條款處理。
- OpenAI：以 ChatGPT 帳號登入 Codex 時，資料使用依你的 ChatGPT 資料控制設定，請自行到 ChatGPT 的設定確認；API 通道送出的資料預設不用於訓練。
- 使用 Codex 時，你自己的 Codex 使用者設定檔（`~/.codex/AGENTS.md`，如果有）會隨每次呼叫一起送出，這是 Codex 本身的行為。本程式已關掉 Codex 的所有工具（不能讀寫檔、不能執行指令）。

::: warning 含個資或受法規限制的錄音
面試、醫療、法律、客服這類錄音，使用 AI 校正與整理前，請先確認是否允許使用雲端 AI；錄影的截圖上可能有與會者的臉與名字、共享畫面上的資料。不確定時，兩題都回答 n，逐字稿仍然完整產出；只想不送截圖時，把 `reference.frames` 改成 `false`。
:::

## 校正版逐字稿

原始逐字稿 `transcript.md` **永遠保持原樣**，AI 另外寫一份 `transcript.corrected.md`，把每一處修改標出來，方便回頭查證：

```markdown
**[00:00:00] 王小明（S1）**：今天討論{範例科及→範例科技}的系統升級，[?七月三號｜七月十三號]上線……
```

| 標記 | 意思 |
|---|---|
| `{原文→修正}` | AI 修改的地方 |
| `{原文→}` | 刪除（幻覺句、跳針重複） |
| `[?原文｜推測]` | 不確定，建議回聽 |
| `姓名（S#）` | 講者對應 |

檔案開頭附「校正摘要」（修了什麼、幾次、依據、要不要加進對照表）、「講者對應」與「待確認」清單。2.2 起，有[參考資料](/features/reference)時表頭下多一行寫明參考了什麼，〈講者對應〉填上從截圖對應到的姓名；同一個英文名詞的不同寫法會[統一](/features/consistency)，統一處同樣用 `{原文→統一}` 標出。

## AI 校正

轉寫完成後，由你電腦上的程式直接呼叫 Claude 或 OpenAI，校正同音錯字與專有名詞，產出：

- `transcript.corrected.md`：校正版逐字稿
- `corrections.suggested.tsv`：建議加進[固定錯誤對照表](/features/accuracy#固定錯誤對照表)的項目（**還沒生效**，你確認後才加入）
- `auto_correct.json`：執行紀錄（不含逐字稿內容與金鑰）
- `reference.json`、`context.md`（2.2，有參考資料時）：AI 從截圖、文件認出的與會者與名詞；入口輸入的背景說明（見[參考資料](/features/reference)）

AI 校正失敗（沒登入、額度用完、網路、逾時）**不影響轉寫**：逐字稿照常完成，之後可以補做，或改在 Claude 對話中校正。

## 會議摘要

把逐字稿整理成 `meeting-minutes.md`（非會議類型是 `notes.md`，見[內容類型](/features/content-types)）：會議摘要、議題討論、決議事項、待辦事項（負責人、期限）、待釐清問題與風險、下次會議，每一項附時間碼。

- 有校正版就用校正版。
- **不杜撰**：只寫逐字稿裡實際講到的；沒講期限就寫「未定」；講者姓名只在能確定時寫，否則保留 S#。
- **參考資料**（2.2）：〈與會者〉補上從截圖對應到的姓名（標「（截圖）」），〈日期時間〉從截圖補上；文件裡有、但會中沒有說的內容不會寫進會議記錄（見[參考資料](/features/reference)）。
- 表頭寫「自動整理：…｜**未經人工確認**」。請對照時間碼回聽，確認決議與待辦。
- 長會議（超過約 45～50 分鐘）分段整理再彙整，段落交界的討論不會被切斷。
- 之後想在 Claude 裡修：附上 `meeting-minutes.md` 與校正版逐字稿，說「用 meeting-minutes-pro 檢查這份會議記錄」，Claude 會當草稿查證、補講者姓名，不會從頭重寫。

## 兩家供應商、兩種通道

| 供應商 | 訂閱通道（預設） | API 通道（選用，尚未用真的金鑰實測） |
|---|---|---|
| Claude（Anthropic） | Claude Code 的 `claude` 指令，用你的 Claude 訂閱額度 | Anthropic Python SDK，環境變數 `ANTHROPIC_API_KEY`，依用量付費 |
| OpenAI | Codex 的 `codex` 指令（唯讀、不執行工具），用你的 ChatGPT 訂閱的 Codex 額度 | OpenAI Python SDK，環境變數 `OPENAI_API_KEY`，依用量付費 |

**預設怎麼選**：找得到 `codex` 指令而且已登入時用 OpenAI `gpt-6.1-sol`；否則找得到 `claude` 指令就用 Claude `opus`；兩個都沒有就不問這兩題（結束畫面會寫怎麼安裝與登入）。

::: info 政策提醒
用自己的訂閱、在自己的電腦上讓程式呼叫 `claude` 或 `codex`，屬於自用情境。若要把這個工具提供給別人使用，請先自行確認 Anthropic 與 OpenAI 對訂閱用於腳本呼叫的條款，或請對方改用 API 通道。
:::

## 每次選模型

回答「是」之後會再問這次用哪個模型。每個選項都附依這次錄音長度換算的預估時間與 API 等價費用：

```text
AI 校正用哪個模型？（錄音 1 小時 19 分；預估依合成素材實測，實際會議可能不同）
  [Enter] 預設（OpenAI gpt-6.1-sol）：約 9 分鐘、API 等價約 US$0.46～0.60
  [2] Claude opus：約 6～7 分鐘、API 等價約 US$1.16～1.36
  [3] Claude sonnet（準確率較低）：約 4～6 分鐘、API 等價約 US$0.53～0.73
  費用是 API 等價估算：用訂閱時不另計費，但會用掉額度
請選擇：
```

- 直接按 Enter 用預設；選 2、3 只影響這一次。
- 「API 等價費用」：如果改用 API 計費大約要多少錢。用訂閱時**不另外收費**，但會用掉方案額度。
- 錄音超過 2 小時，題目前面會多一行黃色提醒，寫明時間與費用。

### 怎麼挑模型（合成素材實測，一小時錄音）

| 模型 | AI 校正 | 會議摘要 | 適合 |
|---|---|---|---|
| OpenAI `gpt-6.1-sol` `low`（有 Codex 時的預設） | 修對約 81～90%，錯改 0～1.5%；約多 7 分鐘 | 決議、待辦涵蓋最多，最便宜；約多 6～8 分鐘 | 一般情況 |
| Claude `opus` `medium`（沒有 Codex 時的預設） | 修對約 78～87%，錯改 1.6～2.8%；約多 5 分鐘 | 寫得最細；約多 4～6 分鐘 | 想用 Claude 訂閱、重要會議 |
| Claude `sonnet` | 準確率最低（長會議漏改明顯較多） | 最快（約 sol 的 1/3 時間），可能漏 1～2 項待辦 | 長會議想少等 |

三種模型在會議摘要都沒有杜撰。數字來自自寫、虛構的合成素材（會議素材 M1、M3 是 2.0.2 換名前的舊版素材），每種設定只跑 1～2 次，你的實際會議（口音、專有名詞、錄音品質）可能不同；模型名稱與預設也可能隨供應商更新而改變。計分方法見[研究方法](/design/research#計分方法)。

## 開關與補做

- **右鍵與拖放轉寫**：每次都會問，直接按 Enter＝是。想改成按 Enter＝否，在 `config.json` 設 `"correction": {"ask_default": false}`、`"minutes": {"ask_default": false}`。
- **Claude CLI 對話**：照安裝時的回答（`correction.enabled`），也可以直接跟 Claude 說「用 sonnet 自動校正」「這次不要自動校正」。
- **補做或重做**（例如當時沒開、或登入後重跑）：

  ```powershell
  & "$MMH\venv\Scripts\python.exe" "$MMH\scripts\auto_correct.py" "<檔名>_minutes" --force
  & "$MMH\venv\Scripts\python.exe" "$MMH\scripts\auto_minutes.py" "<檔名>_minutes" --force
  ```

  已經有結果時要加 `--force`，舊檔會先改名備份。更多參數見[手動執行與參數](/usage/advanced)。
