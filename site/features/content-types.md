# 7 種內容類型

**這頁幫你做到**：知道轉寫前第一題「內容類型」該選哪一個，以及每一種會整理出什麼。

## 類型決定了什麼

- **整理出什麼樣的筆記**：會議產出會議記錄 `meeting-minutes.md`；其他類型產出筆記 `notes.md`（另有結構化資料 `notes.json`）。
- **說話者分離與截圖的設定**：例如課程的分群門檻比較寬（講者通常只有一位）、操作教學的截圖比較靈敏。
- **逐字稿本身不受影響**：選錯了也沒關係，可以只重做筆記（見[選錯了怎麼辦](#選錯了怎麼辦)）。

轉寫前的第一題長這樣，直接按 Enter＝會議；之後會記住你上次選的類型：

```text
內容類型（Enter＝會議）
  1 會議（含業務／客戶會議）       2 課程（含演講／專題分享）       3 訪談節目（Podcast、專訪）
  4 操作教學／示範                 5 座談／論壇／研討會             6 腦力激盪／工作坊／回顧
  7 客戶／需求訪談
請選擇：
```

## 每一種整理出什麼

| 類型 | 適合 | 筆記裡的節（摘要以外） |
|---|---|---|
| **會議** | 例行會議、專案會議、業務或客戶會議 | 議題討論、決議事項、待辦事項（負責人、期限）、待釐清問題與風險、下次會議 |
| **課程** | 上課、演講、專題分享 | 章節、關鍵概念、案例與示範、學員問答、作業與課後事項、提到的資源、下一堂 |
| **訪談節目** | Podcast、專訪 | 段落主題、來賓觀點、重要引述、提到的作品與資源、下一集 |
| **操作教學** | 軟體操作示範、教學影片 | 目標與前置需求、操作步驟（附關鍵畫面）、注意事項、確認方式、問答 |
| **座談** | 論壇、研討會、多位與談人 | 與談人觀點、共識、分歧、觀眾提問、結語、宣布事項 |
| **工作坊** | 腦力激盪、回顧會議 | 目的、發想與意見、投票結果、決定、行動項目、停車場（之後再談的事） |
| **需求訪談** | 客戶訪談、需求訪談 | 現況流程、痛點、需求（自動編號）、限制條件、成功指標、下一步 |

每一種都有：摘要、講者（含各自的發言時間）、待釐清問題、待確認的辨識錯字；每一項都附時間碼。**只寫錄音裡講到的內容，不杜撰**，表頭會寫「自動整理：…｜未經人工確認」，請對照時間碼回聽確認。

## 幾個類型的特別處理

- **訪談節目的重要引述**：程式會拿引述逐字比對逐字稿，對不上（模型改寫了原話）的標 ⚠，請回聽確認。
- **操作教學的關鍵畫面**：影片截圖自動變得比較靈敏，程式依時間把截圖掛到對應的步驟。**只看時間、不看圖片內容**，截圖也不會送給模型。
- **會議的待釐清問題**：只列會中有人提出、到最後都沒有答覆或決定的問題。會中有人說「不確定」「再研究」卻沒講好怎麼決定的，程式會先挑出來提示模型，整理完再補判一次（多一次呼叫，約 5～10 秒）。有程式輔助，但**不保證不漏**，請對照議題查看。
- **長錄音**：超過約 45～50 分鐘的錄音會分段整理再彙整；每段會附上前後段的幾句話當上下文，段落交界的討論不會被切斷。

## 怎麼選

- 有決議、有待辦、要追進度 → **會議**
- 一位講者為主、要整理重點與作業 → **課程**
- 主持人加來賓、重視觀點與引述 → **訪談節目**
- 跟著畫面一步一步做 → **操作教學**（影片效果最好）
- 好幾位與談人輪流發言 → **座談**
- 大家丟點子、投票、決定行動 → **工作坊**
- 了解客戶現在怎麼做、要什麼 → **需求訪談**

面試、醫療、法律、客服沒有內建類型，可以用[自訂範本](/features/custom-templates)延伸「會議」或「需求訪談」。這類錄音多半含個資或受法規限制，AI 整理會把逐字稿文字送到雲端，**使用前先確認是否允許使用雲端 AI**。

## 選錯了怎麼辦

逐字稿不受影響，只要重做筆記（Windows 範例，`$MMH` 是 runtime 資料夾，見[手動執行與參數](/usage/advanced)）：

```powershell
& "$MMH\venv\Scripts\python.exe" "$MMH\scripts\auto_minutes.py" "<檔名>_minutes" --type course --force
```

類型代號：`meeting`（會議）、`course`（課程）、`interview`（訪談節目）、`tutorial`（操作教學）、`panel`（座談）、`workshop`（工作坊）、`requirements`（需求訪談）。說話者分離的門檻也跟類型有關，講者分得不理想時可以重新轉寫。

在 Claude 對話中改過 `notes.json` 之後，加 `--render-only` 就能重新產生 `notes.md`，不必再呼叫模型（會議類型不支援）。

## 實測

在自寫、虛構的合成素材上（每種類型 1 份），講稿重點的涵蓋率 82～100%（寫在別的節也算時 97～100%），時間碼全部對得上，沒有杜撰。64 分鐘的長課程分 2 段整理再彙整，欄位沒有遺失。方法見[研究方法](/design/research#計分方法)。
